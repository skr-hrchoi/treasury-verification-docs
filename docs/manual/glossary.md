# 9. 용어 사전

| 용어 | 쉬운 설명 |
| --- | --- |
| 원천 / Source of Truth | 정답으로 삼는 기준 자료. 이 시스템에서는 사내 자금일보 시스템 SamsApi 입니다 |
| SamsApi | 사내 자금일보 API 서버. 현금·채권 원천 데이터를 제공합니다 (사내망에서만 접속) |
| Supabase | 포털이 데이터를 저장해 두는 외부 데이터베이스. 포털 화면은 여기서 값을 읽습니다 |
| 기대값 (expected) | 검증기가 원천에서 직접 계산해 낸 '이래야 맞다'는 값 |
| 실측값 (actual) | 포털이 실제로 저장·표시하고 있는 값 |
| 갭 (gap) | 기대값 − 실측값. 0이 정상입니다 |
| 허용 오차 (tolerance) | 이 정도 차이는 반올림 때문이니 통과로 본다는 기준선 |
| PASS / FAIL / UNVERIFIABLE | 통과 / 실패 / 검증불가. 검증불가는 '틀렸다'가 아니라 '못 물어봤다'입니다 |
| CRITICAL / WARNING / INFO | 심각도. 위험 / 주의 / 참고 |
| 스냅샷 (snapshot) | 판정에 쓴 그 시점의 원자료 사본. 나중에 되짚기 위해 남깁니다 |
| 사후 재검증 (recheck) | 그때 못 물어봐 물음표로 남은 항목을, 나중에 그날 기준일로 다시 조회해 정정하는 것 |
| 현금 지문 (fingerprint) | 현금 값이 바뀌었는지 한눈에 알기 위해 잔액·환율·화면코드를 요약한 짧은 문자열 |
| 회귀 (regression) | 어제까지 정상이던 항목이 오늘 새로 깨진 것. 원인 찾기의 출발점입니다 |
| 기준일 (as_of) | 그 숫자가 '언제 자'인지. 자금 데이터는 보통 전일 기준입니다 |
| 시재 / 현금(1001) | 은행에 들어 있지 않고 회사가 직접 들고 있는 현금. 총계에서 은행 명세 합을 뺀 금액 |
| HTTP 429 | '요청이 너무 잦습니다'라는 서버의 거절 응답. 사내 API 속도제한에 걸렸다는 뜻 |
| 내부 정합성 | 외부와 비교하지 않고, 저장된 데이터 안에서 '반드시 같아야 하는 합'을 확인하는 것 |
| 교차검증 | 같은 값을 성격이 다른 제2의 출처로 한 번 더 확인하는 것 (예: 네이버 종가 ↔ 야후 종가) |
