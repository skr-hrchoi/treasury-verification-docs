# 6. 이상이 생겼을 때 — 대응 절차

## 6.1 「실패(FAIL)」를 발견했을 때 {: #61-fail }

1. 대시보드를 엽니다. (`reports\dashboard.html`)
2. 오늘 날짜 칸을 클릭하고 **「회귀 추적」을 먼저** 봅니다.
   어제까지 정상이었다가 오늘 새로 깨진 항목이 원인에 가장 가깝습니다.
3. 상세 표에서 그 항목의 **기대값 · 실측값 · 갭**을 확인합니다.
   차이가 몇 원 수준인지 억 단위인지에 따라 성격이 다릅니다.
4. 어느 층의 문제인지 가늠합니다.
   ① 원천 자료가 바뀐 것인가 ② 수집이 덜 된 것인가 ③ 포털 화면 계산이 틀린 것인가 ④ 검증기 쪽 문제인가.
5. 포털 숫자가 실제로 틀렸다고 판단되면, **경영진 보고나 대외 공유 전에 먼저 보류**하고 조치합니다.
6. 조치 후 손으로 재검증합니다([7장](run-manually.md)). 통과로 바뀌면 대시보드가 함께 갱신됩니다.

!!! warning "이럴 때 특히 주의"
    「데이터를 올렸는데 포털에 반영이 안 됐다」는 증상은 배포 문제가 아니라
    **업로드 완료 신호(inbox_pending)의 고장**인 경우가 많습니다.
    배포부터 뒤지지 말고 그쪽을 먼저 확인하십시오.

## 6.2 「검증불가(UNVERIFIABLE)」가 떴을 때 {: #62-unverifiable }

검증불가는 값이 틀린 것이 아니라 '그 순간 물어보지 못한' 상태입니다.
원인은 대부분 사내 API SamsApi 의 속도제한(HTTP 429)입니다.

| 상황 | 판단 | 조치 |
| --- | --- | --- |
| 하루치 검증불가, 다음 날 정상 | 정상 범위. 사후 재검증이 자동으로 정정합니다 | 지켜보면 됩니다 |
| 같은 항목이 **3일 이상** 검증불가 | 사내망 접속 · API 키 만료 · 원천 시스템 변경 의심 | [6.4절 점검표](#64) 수행 |
| 현금 화면 검사가 검증불가 | node 실행 불가 또는 포털 스냅샷 없음. **자동 정정 대상이 아님** | `자금관리포털\홈페이지배포\snap\` 아래 `assets` · `cash-detail` 폴더에 파일이 있는지 확인 |

## 6.3 검증이 돌았는지 확인하는 법 (조용한 실패 점검) {: #63 }

!!! danger "검증이 멈춰도 먼저 알려 주는 것은 없습니다"
    PC가 꺼져 있거나 작업 스케줄러가 멈추면 **아무 소리 없이** 그날 검증이 건너뛰어집니다.
    그래서 '이상이 없으면 조용하다'가 아니라, 아래 ①번으로 눈으로 확인해야 합니다.

**① 돌았는지 확인하는 방법**

- 대시보드를 열어 맨 윗줄 「생성 (날짜 시각)」이 오늘 09:10 인지 봅니다.
  어제 날짜에 멈춰 있으면 오늘 검증이 돌지 않은 것입니다.
- 달력에서 오늘 칸이 비어 있는지 봅니다. 평일인데 비어 있으면 미실행입니다.

**② 미실행이 확인되면**

1. 09:10에 PC가 켜져 있고 로그인되어 있었는지 확인합니다.
2. 작업 스케줄러에서 `자금관리포털_대시보드검증` 이 '준비(Ready)' 상태이고
   마지막 실행 시각이 오늘인지 확인합니다.
3. 주말이면 미실행이 정상입니다. (공휴일은 평일이면 **실행되는 것이 정상**입니다 — [4.5절](schedule.md#45))
4. 그래도 원인을 모르면 [7장](run-manually.md)의 수동 실행으로 직접 한 번 돌려보고,
   화면에 나오는 오류 메시지를 확인합니다.

## 6.4 점검표 {: #64 }

| 확인할 것 | 정상 상태 | 확인 방법 |
| --- | --- | --- |
| 작업 스케줄러 등록 | `자금관리포털_대시보드검증` 이 준비(Ready), 트리거 평일 09:10 | 작업 스케줄러 → 작업 스케줄러 라이브러리 |
| 사내망 접속 | SamsApi 서버에 도달 가능 | 사내망(VPN 포함) 연결 상태 확인 |
| 접속 키 | `.env` 의 `COMPANY_API_KEY` / `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` 가 채워져 있음 | `.env` 파일 확인 (값은 외부 공유 금지) |
| Python 실행기 | `py --version` 이 3.11 이상 | 명령 프롬프트에서 `py --version` |
| Git Bash | `C:\Program Files\Git\bin\bash.exe` 존재 | `run_verification.cmd` 가 이 경로를 찾음 |
| node | `node` 명령이 동작 (현금 화면 검사에 필요) | 명령 프롬프트에서 `node --version` |
| 포털 스냅샷 | `자금관리포털\홈페이지배포\snap\{assets, cash-detail}\*.json` 존재 | 현금 화면 검사의 원자료 |
