# 데이터와 접근 권한

## 어떤 데이터를 어디서 읽나

| 데이터 | 어디서 | 무엇에 쓰나 | 접근 방법 |
| --- | --- | --- | --- |
| 자금일보 (현금 원천) | 사내 **SamsApi** | 총 보유현금·시재 기대값 재계산 | 사내망 전용, `X-API-Key` 헤더 |
| 채권 매입·평가 (원천) | 사내 **SamsApi** | 채권 매입금액·평가단가·보유목록 기대값 | 〃 |
| 포털 저장 현금 | **Supabase** `cash_detail` | 실측값 (총계·통화별) | REST, 조회 키 |
| 포털 저장 지사합계 | **Supabase** `branch_totals` | 실측값 (지사별·전체합) | 〃 |
| 포털 저장 채권·주식 | **Supabase** `cash_assets` (`payload.bonds[]`, `payload.stocks[]`) | 실측값 | 〃 |
| 포털 화면 원자료 | 자금관리포털 `홈페이지배포\snap\assets\{회사}.json`<br>`…\snap\cash-detail\{회사}.json` | 현금 화면 기대값 독립 재계산·두 소스 대조 | 같은 PC의 파일 |
| 포털 화면 결과 | 포털 `app.js` 를 node 로 실행한 출력 | 화면에 실제로 찍히는 값 | 같은 PC에서 실행 |
| 주식 종가 (제2 소스) | 야후 파이낸스 | 현재가 교차검증 | 공개 인터넷, 인증 없음 |

!!! note "원천의 합계행을 그대로 믿지 않습니다"
    총 보유현금은 SamsApi 응답의 합계행(TOT)을 쓰지 않고, **통화별 행을 직접 합산해 재구성**합니다.
    원천 쪽 집계가 바뀌어도 검증기가 같이 틀리지 않게 하려는 것입니다(설계 원칙 ②).

## 어떤 데이터를 남기나

모두 **그 PC 안에만** 남습니다. 외부로 보내지 않습니다.

| 경로 | 내용 | 민감도 | 보존 |
| --- | --- | --- | --- |
| `reports\<일시>.json` | 그 실행의 판정 결과 전체 (기대값·실측값 포함) | **금액 포함** | 일자별 1개(같은 날 최종본만) |
| `reports\latest.json` | 가장 최근 실행 복사본 | **금액 포함** | 덮어씀 |
| `reports\dashboard.html` | 달력형 대시보드 (데이터가 파일 안에 박혀 있음) | **금액 포함** | 매 실행 재생성 |
| `snapshots\<일시>\*.json` | 판정에 쓴 원천 응답·포털 값 원본 | **금액 포함** | 일자별, 약 30MB 누적 |
| `logs\cash-recheck.log` | 현금 재검증 기록 | 판정만 (금액 없음) | 누적 |
| `logs\.cash-fingerprint`<br>`logs\.cash-verdict.json` | 현금 지문 해시, 직전 현금 판정 7건 | 금액 없음 | 덮어씀 |

이 산출물은 모두 **버전관리에서 제외**되어 있습니다(`.gitignore`).
공개 문서 저장소에도 들어가지 않습니다.

## 접근 키

키는 `.env` 파일에만 둡니다. 코드·설정(yaml)·문서에는 **이름만** 적습니다.

| 환경변수 이름 | 무엇 | 주의 |
| --- | --- | --- |
| `COMPANY_API_KEY` | 사내 자금일보 API 인증 | 사내망에서만 유효 |
| `SUPABASE_URL` | 포털 데이터 저장소 주소 | |
| `SUPABASE_SERVICE_ROLE_KEY` | 포털 데이터 조회 키 | **접근 제한을 통과하는 키** — 취급 주의 |

설정 파일(`metrics.yaml`)에는 `api_key_env: "COMPANY_API_KEY"` 처럼 **환경변수 이름**만 적고,
URL 안의 `${SUPABASE_URL}` 도 실행할 때 치환됩니다. 값이 파일에 남지 않습니다.

## 권한 범위 — 검증기가 할 수 있는 일

| | |
| --- | --- |
| **읽기** | 사내 원천 조회, 포털 저장 데이터 조회, 포털 스냅샷 파일 읽기 |
| **쓰기** | 자기 폴더(`reports\` · `snapshots\` · `logs\`)에만 |
| **하지 않는 것** | 포털 데이터 수정 · 삭제 · 배포 · 외부 전송 |

무인으로 도는 프로그램이라 파괴적 동작은 설계 단계에서 금지되어 있습니다
([설계 원칙과 개발 규칙](conventions.md)).

## 개인정보

이 시스템이 다루는 것은 **회사 자금 수치**입니다.
개인을 식별할 수 있는 정보(이름·연락처·계좌 명의 등)는 읽지도, 저장하지도 않습니다.
지사·은행 단위 잔액과 종목 단위 금액까지만 다룹니다.
