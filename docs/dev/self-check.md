# 문서 자가 검증

## 왜 있나

매뉴얼은 사람이 읽고 **그대로 믿는** 문서입니다.
'설계상 그렇다'와 '지금 실제로 그렇다'가 갈라지면 문서가 오히려 사고를 만듭니다.

실제로 2026-09-10 초안에는 「텔레그램 알림으로 결과를 받는다」, 「공휴일에는 검증이 돌지 않는다」처럼
**설계 의도가 현재 동작인 것처럼** 적힌 대목이 있었습니다. 둘 다 사실이 아니었습니다.

그래서 문서에 적은 숫자·시각·경로·상태를 **프로그램이 다시 확인**합니다.

## 실행

```bat
cd /d <검증시스템 폴더>
py docs\verify_manual_facts.py
```

- 종료코드 `0` = 전부 일치
- 결과는 화면 출력 + `docs\매뉴얼_자가검증결과.txt` (UTF-8)
- `--json <경로>` 로 기계가 읽을 형태로도 낼 수 있습니다

```
매뉴얼 자가 검증 결과 — 26/26 항목 일치

[일치]  1. (표지·3장) 가장 최근 실행(reports/latest.json)의 검사 항목은 36개다
        근거: latest.json 항목 수 = 36
[일치]  7. (4.1절) 전체 검증은 작업 스케줄러 「자금관리포털_대시보드검증」이 평일(월~금) 09:10 에 ...
        근거: 작업='자금관리포털_대시보드검증' 상태=Ready 트리거=...|62| 동작=...run_verification.cmd auto
...
```

## 무엇을 확인하나 (26항목)

| 갈래 | 확인하는 것 | 근거로 읽는 대상 |
| --- | --- | --- |
| 검사 구성 | 항목 수 36, 갈래별 개수, 회사별 구성(한성 채권 0 · 주식은 장금만) | `reports/latest.json` |
| 실행 일정 | 검증 09:10 평일, 자동배포 매시 05분, 수집 크론 8회 | Windows 작업 스케줄러, `server.js` |
| 공휴일 | 실행 파일에 공휴일 분기가 **없음** | `run_verification.sh` · `.cmd` |
| 현금 재검증 | 하루 호출 22 = 변경없음 15 + 재계산 7 | `auto-deploy.log` · `cash-recheck.log` |
| 알림 | 밖으로 보내는 알림 채널이 설정돼 있지 않음 | `.env` · `logs/notify.log` |
| 설정값 | 허용 오차 7종, 회사 3곳 | `config/metrics.yaml` |
| 실행 순서 | 매뉴얼의 ①~⑧ 이 실제 순서와 같음 | `run_verification.sh` |
| 명령 | 문서에 적은 CLI 옵션이 실제로 존재 | 각 스크립트의 `argparse` |
| 파일 | 문서에 경로가 적힌 파일이 실제로 존재 | 파일 시스템 |

## 검사를 추가하는 법

`@check(절, 주장)` 데코레이터로 등록하고, `(참/거짓, 근거문자열)` 을 돌려주면 됩니다.

```python
@check("4.4절", "사후 재검증(recheck.py)은 기본 14일치 리포트를 훑는다")
def c_recheck_days():
    s = read(os.path.join(ROOT, "checks", "recheck.py"))
    m = re.search(r'"--days".*?default=(\d+)', s)
    return bool(m) and m.group(1) == "14", f"recheck.py --days 기본값 = {m.group(1) if m else '찾지 못함'}"
```

!!! tip "근거 문자열이 핵심입니다"
    「일치」라는 글자만 나오면 믿을 수 없습니다.
    **실제로 읽은 값**을 근거로 함께 내십시오. 틀렸을 때 무엇이 어떻게 다른지 바로 보입니다.

## 작업 스케줄러를 읽는 방법

작업 이름에 한글이 섞여 있어 PowerShell `-Command` 로 넘기면 5.1 에서 깨집니다.
그래서 **실행하는 동작(Action) 경로로 찾고**, 결과는 UTF-8 파일로 받아 읽습니다.

```python
# 임시 .ps1 을 UTF-8 BOM 으로 쓰고 -File 로 실행 → ConvertTo-Json | Out-File -Encoding utf8
def task_by_action(needle: str) -> dict: ...
```

## 문서를 고칠 때의 규칙

!!! important "문서와 확인 프로그램은 한 쌍입니다"
    매뉴얼·이 사이트의 사실을 고치면 `verify_manual_facts.py` 도 함께 고치십시오.
    절 번호가 바뀌면 `@check` 의 첫 인자도 바꿔야 합니다.
    확인 프로그램이 낡으면 자가 검증은 **아무것도 지켜 주지 않습니다.**

## 같은 내용이 두 곳에 있는 문제

지금 같은 내용이 **이 사이트(Markdown)** 와 **Word 매뉴얼(`build_manual.py`)** 두 곳에 있습니다.
복사본은 시간이 지나면 갈라집니다.

- 기준은 **이 사이트**입니다. Word 판은 인쇄·메일 첨부용 사본입니다.
- 사실이 바뀌면 `verify_manual_facts.py` 가 **양쪽 모두에 대해** 어긋남을 알려 줍니다
  (문서 파일이 아니라 '주장'을 실제 시스템과 대조하기 때문입니다).
- 그래도 문구까지 자동으로 맞춰 주지는 않으므로, 한쪽만 고치고 끝내지 마십시오.
