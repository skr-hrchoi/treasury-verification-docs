# 자금관리포털 데이터 검증 시스템

포털 화면에 찍히는 숫자가 원천 자료(사내 자금일보 시스템 SamsApi)와 정말로 같은지를,
사람 대신 **매일 아침 자동으로 대조해 보고 알려주는 감시 장치**입니다.

!!! info "이 문서에 싣지 않는 것"
    공개 문서이므로 **실제 보유 금액 · 사내 서버 주소 · 접속 키**는 싣지 않습니다.
    본문의 금액과 화면 캡처는 모두 **지어낸 예시 값**이고, 사내 주소는 「사내 문서 참조」로 대신합니다.
    실제 수치는 사내 대시보드(`reports\dashboard.html`)와 사내 Word 매뉴얼에서 확인하십시오.

## 한 장으로 보는 구조

포털의 숫자는 원천에서 화면까지 여러 단계를 거칩니다. 단계마다 어긋날 수 있는 지점이 있고,
이 시스템은 그 지점을 **층별로 나눠** 짚습니다.

```
[사내 SamsApi]  →  [수집·가공]  →  [Supabase 저장]  →  [화면 계산]  →  [사람이 보는 숫자]
       │                  │                │                 │
       └── ① 원천과 ──────┴── ② 저장된 값 ─┴── ③ 화면에 ─────┘
           같은가?            끼리 앞뒤가       찍히는 값이
                              맞는가?           맞는가?
```

| 검사하는 층 | 확인하는 질문 | 해당 검사 |
| --- | --- | --- |
| ① 원천 대비 | 포털이 들고 있는 값이 사내 자금일보와 같은가 | 총 보유현금 · 시재 · 채권 매입금액 · 평가단가 · 보유목록 |
| ② 저장 데이터 내부 | 저장된 값끼리, 정의상 반드시 맞아야 할 합이 맞는가 | 지사별 통장합계 · 현금 통화별 합계 · 주식 요약↔종목합 |
| ③ 화면 계산 | 화면 코드를 실제로 돌렸을 때 나오는 숫자가 맞는가 | 현금 화면 정합성 (총보유현금 · 통화별 · 계열사별 · 추이그래프) |
